# Threat Hunt 001: PowerShell Temporary File Correlation

## 1. Objective

Investigate whether PowerShell execution followed by temporary-file creation indicates suspicious scripting activity. Correlate Sysmon process-creation and file-creation events to distinguish routine system activity from behavior requiring further investigation.

## 2. Hunt Hypothesis

PowerShell execution followed by file creation in a temporary directory may indicate suspicious script activity. Correlating process and file events can provide context to distinguish legitimate administrative operations from potentially malicious behavior.

## 3. Environment

- **SIEM:** Wazuh 4.14.8
- **Endpoint:** Windows 10 virtual machine
- **Telemetry source:** Sysmon Operational log
- **Log source:** Wazuh alerts and archived events
- **Events examined:** Sysmon Event ID 1 (Process Create) and Event ID 11 (File Create)
- **Hunt period:** 11–12 October 2026

## 4. Investigation Findings

### Process Creation

On 12 October 2026 at approximately 14:54:49 UTC, PowerShell executed under `NT AUTHORITY\SYSTEM`.

- **Process ID:** `4896`
- **Process GUID:** `{f3ab36c2-f4b9-6acc-8900-000000000a00}`
- **Parent process:** `wazuh-agent.exe`
- **Parent PID:** `3464`
- **Wazuh rule:** `92021`
- **Event ID:** `1`

The command exported local security policy settings using `secedit`, queried the `MaximumPasswordAge` setting, and attempted to remove the temporary configuration file `secpol.cfg`.

### File Creation

At approximately 14:54:58 UTC, Sysmon recorded a file-creation event associated with the same PowerShell process.

- **Event ID:** `11`
- **Process ID:** `4896`
- **Process GUID:** `{f3ab36c2-f4b9-6acc-8900-000000000a00}`
- **Target file:** `C:\Windows\Temp\__PSScriptPolicyTest_3zpahwxg.ley.ps1`
- **Wazuh rule:** `92201`
- **Execution context:** `NT AUTHORITY\SYSTEM`

The process GUID matches the process-creation event, establishing that the file-creation event was generated by the same process instance.

### Correlation

The two events were correlated using the process GUID, with PID and timestamps as supporting fields. The file was created approximately 8.6 seconds after the PowerShell process started.

The filename pattern `__PSScriptPolicyTest_*.ps1`, the Wazuh Agent parent process, and the security-policy inspection command are consistent with routine PowerShell script-policy testing associated with security configuration assessment.

## 5. Assessment

**Classification: Likely benign activity.**

The available evidence supports a legitimate Wazuh Agent security configuration assessment as the most likely explanation. The filename pattern and process context are more consistent with routine assessment activity than with an independently established malicious execution chain.

This is a reasoned classification based on the collected events, not proof that every event involving a similar filename is benign.

## 6. Telemetry Limitations

A matching file-deletion event was not established during this investigation. Although the PowerShell command contains `Remove-Item`, the command line alone does not prove that deletion succeeded.

The hunt therefore confirms process creation and subsequent file creation, but does not confirm the complete file lifecycle.

The investigation also demonstrates that event-level ATT&CK metadata should be interpreted alongside the actual process command, parent process, filename, and correlated telemetry rather than treated as conclusive evidence of malicious behavior.

## 7. Detection Engineering Decision

No new detection rule was created from this finding.

The existing alerts provided sufficient telemetry to identify and investigate the behavior. Creating a new rule based solely on this benign pattern could introduce duplicate alerts or false positives.

Future detection tuning should prioritize suspicious context and correlated behavior rather than broadly alerting on all PowerShell temporary-file creation.

- Correlated Sysmon Event ID 1 and Event ID 11 using the process GUID.
- Identified a likely benign PowerShell script-policy testing pattern.
- Documented the classification and supporting evidence.
- Identified the lack of confirmed file-deletion telemetry as a limitation.
- Avoided introducing an unnecessary detection rule based on a likely benign event.

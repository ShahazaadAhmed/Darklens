# Stage 1: SOC Foundations

## Objective

Establish the fundamental concepts required to build and operate the DarkLens security monitoring platform.

## Core Concepts

### SIEM

A Security Information and Event Management (SIEM) platform collects, correlates, searches, and analyzes security events from different sources.

In DarkLens, Wazuh provides the initial SIEM/XDR capabilities used for centralized security monitoring.

### Telemetry

Telemetry is security-relevant information generated by systems and applications.

Examples include:

- Process creation
- Authentication events
- Network connections
- File activity
- System events

Telemetry provides the evidence required for detection and investigation.

### Sysmon

Sysmon is a Windows system monitoring service that generates detailed telemetry about system activity.

Examples include:

- Process creation
- Network connections
- Process relationships
- File creation events

### Wazuh Agent

The Wazuh Agent runs on an endpoint and collects security-relevant telemetry before forwarding it to the Wazuh Manager.

### Wazuh Manager

The Wazuh Manager receives endpoint telemetry, processes and analyzes events, applies detection logic, and generates alerts.
